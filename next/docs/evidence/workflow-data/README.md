## Reproduce

With Node 24, run `npm ci` in `next/web`, then start `npx vite --host 0.0.0.0`. Open `/test/workflow-data.html`. The fixture covers long `groups[].conflicts`, objects, scalars, explicit null, hostile strings, Unicode, 299/300/301-byte values, a long single string and an ordinary JSON fence. `?unrelated` includes a different attachment also named `data.json`; `?reference` exercises an oversized transcript reference (the browser script mocks its file response). `?integrity` covers exact large-integer/exponent tokens, the canonical 301-byte boundary and JSON nested 7,000 levels deep. `?transcript` mounts the actual `SessionThread`; its test serves encoded data and owning indices through the normal HTTP client for an input, a post and a steer.

Install Playwright outside the checkout, for example `npm install --prefix /tmp/workflow-data-browser playwright`, then run:

```
node test/workflow-data.browser.mjs /tmp/workflow-data-browser/node_modules/playwright/index.mjs /tmp/workflow-data-shots
node test/workflow-data-integrity.browser.mjs /tmp/workflow-data-browser/node_modules/playwright/index.mjs
```

The script uses `/usr/bin/chromium`. It checks light/dark at 1280/390px: no JSON wall or child tree before expansion, native keyboard disclosure, folded long arrays, 50-item paging, safe hostile text, exact byte boundaries, no horizontal page overflow, scroll-to-bottom and no page errors. Focused assertions cover typed associated-file suppression without filtering an unrelated `data.json` or shifting its media-viewer position; one-line small data with Copy only on hover/focus and no Download; unquoted muted array indices versus quoted object keys; and three-line strings with keyboard Show all/Show less. Clipping never changes complete Copy/Download bytes. It also checks lazy oversized-reference loading, a failed fetch and Retry, a same-hash transcript refresh retaining loaded/paged state without refetching, and a byte-exact 1000-entry download.

## Canonical data and transcript integrity

Internal data fields carry JSON text as a string, not parsed JavaScript values. The workflow `post()` value interface is unchanged. The owning boundary rejects invalid literal UTF-8 before compacting and HTML-escaping the JSON. API reads, pending/quote state, forwarding, Copy, Download and byte thresholds retain this canonical text. The web indexes source ranges iteratively and creates child nodes only for an opened page; number tokens are not converted, and folded 7,000-deep JSON does not require recursive parsing or reserialization. Only individual string tokens are decoded for human-readable presentation; actions use the original source.

`TestWorkflowCanonicalDataWireAndForward` exercises encoded request/read/server-forward/browser-forward round trips, including large integers, exponent and negative-zero spellings, explicit null and the JSON string `"null"`. `TestWorkflowTranscriptDataOwnership` reads the real transcript endpoint and post/steer adapters, retaining both canonical data and index 1 beside an unrelated `data.json`. `TestWorkflowDeepDataAndOwnedTranscriptReference` accepts 7,000-deep JSON and proves a reference uses the owning index rather than the first same-hash file. Literal UTF-8 boundary tests reject invalid, overlong and truncated sequences while allowing literal Unicode and escaped surrogates; the encoded-wire codec rejects invalid UTF-8 and non-string fields.

The integrity browser test checks exact visible numeric tokens, Copy/Download, the 301-byte exponent chip and bounded deep disclosure. It exercises actual transcript input/post/steer components through mocked HTTP responses, suppressing only the associated file and opening an image at its original index 2 while an unrelated same-name JSON card remains. The Go endpoint tests cover real transcript response generation; browser HTTP/file responses are not a claim of live end-to-end server testing.

The original-head numeric/threshold/deep repro was executed under Node 24 and produced three assertion failures. New encoded-wire, transcript ownership and literal UTF-8 tests also failed before their fixes. All 15 Go and 15 web mutations are assertion-killed, including numeric/size/forward reconstruction, eager deep reserialization, dropped input/post/steer ownership, content/name-based file guessing and removed UTF-8 checks. Compiler failures and timeouts do not count as kills.

## Delivery proof

`go test ./engine -run 'TestWorkflow(PostData|FinalData|HugeTranscript|Data|CanonicalData|TranscriptData|DeepData)' -v` covers post and final-result byte boundaries 1023/1024/1025, Unicode bytes, absence/null/array/object/scalar values, preserved text, typed associated-file identity, feed/transcript contracts, forwarding, idempotent retries, JSON MIME reuse, and oversized transcript references. Large-value tests connect the actual recipient `agent.Client.Attach` over a Unix socket to the engine's authenticated `Files` route. They assert the logical `/box/attachments/<seq>/data.json` path and read exact bytes at the corresponding input path in an isolated recipient root, check permissions, and replay the download. The test-only root mapping keeps this proof runnable on CI hosts without a writable `/box`. This is real file/route/client coverage in the test box, **not** a separate-container or remote-host claim. Feed and transcript presentation filtering do not remove stored or agent files. Same-size recipient-cache tampering is inherited SDK behavior, was explicitly outside this repair, and is not claimed as covered by the initially absent destination/replay proof.

Post boundary/value tests failed before implementation (data was lost). The post and final-delivery tests were also run against the spec-only commit, where final JSON remained a wall and no file was delivered. All four final UI policies failed in a browser before their implementation; typed file identity also failed first. Mutation checks separately disable claimed policies, including the recipient's physical file write; outcomes and test counts are recorded in the PR.

**Not checked locally:** separate Podman recipient-container tests (Podman/image harness unavailable), remote-host transport, real screen-reader output, Safari/Firefox. The browser check uses Chromium; its oversized-reference route is mocked. Existing arbitrary text/JSON fences are not migrated or reinterpreted. A JSON-looking final string is text, not structured result data.
