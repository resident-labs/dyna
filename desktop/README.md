# Dyna desktop

Linux needs `webkit2gtk-4.1` and `gtk3`. The `webkit2_41` build tag selects
WebKitGTK 4.1. You do not need the Wails CLI.

From the repository root, run:

```sh
desktop/build.sh
desktop/build/bin/dyna-desktop
```

See the [desktop guide](../docs/desktop/README.md) for setup and use.
